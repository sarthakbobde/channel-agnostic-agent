Architecture one-pager

Channel Agnostic Agent Architecture

One knowledge-base question-answering core. Slack, Microsoft Teams and Google Chat plug into it through thin adapters. Channels and their credentials are added, tested and switched on from an admin page, so changing a channel needs configuration, not changes to the answering code.

System

One question, end to end

  1. Message arrives.

    The adapter checks Slack's connection, a Microsoft token or a Google token, and turns the event into a common Envelope.

  2. Route.

    The model decides whether the message needs a lookup. Greetings and small talk skip retrieval; anything unsure searches. Follow-ups are rewritten into standalone queries.

  3. Retrieve.

    Chroma returns the closest chunks of the indexed documents. Nothing above the score threshold means a fixed "couldn't find this" answer and no model call.

  4. Answer.

    The model answers only from those chunks and cites them, with a fixed scope and identity prompt that treats document text as untrusted.

  5. Reply.

    The adapter formats the text for the platform, adds a Sources line (file and page), and sends it back. The turn is saved to memory.
